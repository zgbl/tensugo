User Guide

TensuGo ユーザーガイド

TensuGo は棋譜のレビューとローカル KataGo 分析のための囲碁アプリです。Windows 64-bit と Mac Apple Silicon に対応しています。

Windows MSImacOS DMG

現在のバージョン：V0.7.50（更新日 2026-08-21）。

V0.7.50 の新機能

検討局面からの出題、目標レベル別の解答とランキング。エンジンは通常/擬人デュアルモード設定とメモリ監視に対応。研究文書は盤面切り抜き、プレビューウィンドウ、PDF・一括エクスポートに対応。バッチ分析コンソールを追加。

TensuGo のインストール

Windows 64-bit

  1. Windows x64 インストーラーをダウンロードします。
  2. インストーラーを実行します。
  3. 初回起動後、設定 > エンジン を開きます。
  4. KataGo の状態を確認します。

Windows 版には KataGo OpenCL エンジンが含まれています。

Mac Apple Silicon

  1. Mac Apple Silicon 版をダウンロードします。
  2. TensuGo をインストールして起動します。
  3. Homebrew で KataGo をインストールします。
  4. 設定 > エンジン で Auto Detect をクリックします。
  5. 検出された設定を選び、Test Engine を実行します。
brew install katago

Mac 版にはエンジンとモデルは含まれません。

KataGo の設定

設定 > エンジン でエンジン一覧と選択中の設定を確認できます。

Auto Detect
システム内の KataGo、モデル、設定ファイルを検索します。
Test Engine
現在の設定でエンジンが起動するか確認します。
Choose Config
KataGo GTP 設定ファイルを手動で選択します。
保存 / デフォルト
設定を一覧に保存し、既定の分析エンジンにします。
Reset to Default
現在の既定設定を消去します。

起動時に自動検索は行いません。必要なときに Auto Detect を実行してください。

Mac KataGo

Homebrew を推奨します。

brew install katago
katago version

通常のパスは /opt/homebrew/bin/katago、モデルは /opt/homebrew/share/katago/ です。検出後に Test Engine を実行してください。

Windows KataGo

設定 > エンジン で Auto Detect をクリックし、検出された設定をテストして既定にします。失敗した場合は Engine、Model、Config を手動で指定してください。

手動コマンド

特殊な起動引数が必要な場合は手動コマンドを使用します。

/opt/homebrew/bin/katago gtp -model /path/to/model.bin.gz -config /path/to/gtp.cfg

入力後に手動設定を追加します。Auto Detect はこのコマンドを変更しません。

よくある質問

Mac で KataGo が見つからない

katago version を実行し、見つからなければ brew install katago を実行してから Auto Detect を再試行してください。

エンジンテストに失敗する

  • Engine Path が KataGo を指しているか確認します。
  • Model Path が .bin.gz を指しているか確認します。
  • Config が GTP 設定ファイルを指しているか確認します。

Mac でメモリ使用量が減らない

macOS はメモリ圧縮とスワップでメモリを管理しており、アプリが解放したメモリはすぐに空きとして扱われず、圧縮/キャッシュページに残ってメモリ負荷が高まったときに回収されます。これは macOS のネイティブなバグであり、TensuGo の不手際ではありません——TensuGo はメモリを正常に解放していますが、macOS が占有をすぐにシステムへ戻さないだけです。TensuGo の AI 分析は一度に多くのメモリを確保するため、この「すぐ戻らない」現象が目立ち、Activity Monitor では高いままに見えます。プロセスを終了するとメモリは完全に回収され、使用量もすぐ下がります。

使い終わったら TensuGo を終了（Cmd+Q）してください。席を離れて分析を長時間実行したままにしないでください。
