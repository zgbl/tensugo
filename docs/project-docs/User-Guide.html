User Guide

天书阁（TensuGo）用户指南

天书阁（TensuGo）是一个围棋棋谱复盘和 KataGo 辅助分析工具。 当前发布重点支持 Windows 64 位和 Mac Apple Silicon（M1/M2/M3/M4）。

下载 Windows MSI 下载 macOS DMG

暂不提供 Windows 32 位和 Intel Mac 安装包。当前版本：V0.7.50（更新于 2026-08-21）。

V0.7.50 新功能

出题与做题

从复盘局面（AI 分析后）创建题目，支持 A/B 两种题型与自动出题标记；按目标级别做题，做题结果支持排名。

拟人引擎与人机对弈

引擎配置可同时保存普通（Normal）与拟人（Human）两套 Model/Config；拟人引擎的候选数、水平偏移可调。

研究文档

棋盘截图裁剪、变化图/PV 研究、PDF 与打包 HTML 导出、独立预览窗口、右侧栏编辑。

批量分析与引擎监控

批量分析控制台实时查看日志与进度（可暂停/继续）；分析时显示引擎内存占用。

安装 TensuGo

Windows 64 位

  1. 下载 Windows x64 安装包。
  2. 运行安装程序。
  3. 第一次打开后进入 设置 > 引擎。
  4. 确认 KataGo 引擎状态。

Windows x64 版本内置 KataGo OpenCL 引擎（2026.5 版本）， 是当前推荐给多数用户的安装方式。

Mac Apple Silicon

  1. 下载 Mac Apple Silicon 安装包。
  2. 安装并打开 TensuGo。
  3. 通过 Homebrew 安装 KataGo。
  4. 打开 设置 > 引擎，点击 Auto Detect。
  5. 选择检测到的 Homebrew KataGo 配置。
  6. 点击 Test Engine 验证引擎可以启动。
  7. 点击 设为默认。
brew install katago

Mac 版当前不把 KataGo 引擎和模型打进安装包。用户需要自己通过 Homebrew 安装 KataGo， TensuGo 负责自动检测和配置。

KataGo 引擎配置

进入 设置 > 引擎 后，可以看到引擎列表和当前选中配置。每个配置可以同时保存普通（Normal）与拟人（Human）两套 Model/Config，分析时按需要切换。

Auto Detect
手动扫描系统里的 KataGo、模型和配置文件。
Test Engine
测试当前配置是否能启动。
选择
手动选择 Engine 或 Model。
Choose Config
手动选择 KataGo GTP 配置文件。
另存为新配置
把当前填写的内容保存为一个新的引擎配置。
更新当前配置
把修改写回当前选中的配置。
设为默认
把当前配置设为默认分析引擎。
删除
删除当前高亮的配置行。
Reset to Default
清空当前默认配置，不会自动扫描系统路径。
诊断
查看引擎路径、状态等信息。

TensuGo 启动时不会自动扫描系统路径。只有点击 Auto Detect 才会扫描。分析时面板会显示引擎内存占用，便于发现长时间分析导致的内存失控。

Mac KataGo 安装说明

推荐方式是 Homebrew：

brew install katago

安装完成后，常见路径类似：

  • Engine: /opt/homebrew/bin/katago
  • Model: /opt/homebrew/share/katago/...bin.gz
  • Config: /opt/homebrew/share/katago/configs/gtp_example.cfg

如果 Auto Detect 找到了多个配置，优先选择 Homebrew 路径下可用的一项， 然后点击 Test Engine。

Windows KataGo 安装说明

Windows 版只支持 64 位安装包。当前发布流程以 Windows x64 为目标，不提供 Windows 32 位版本。 安装后进入 设置 > 引擎：

  1. 点击 Auto Detect。
  2. 如果发现可用引擎，选中后点击 Test Engine。
  3. 测试通过后点击 设为默认。
  4. 如果自动检测失败，可以手动选择 Engine、Model、Config。

高级：手工命令配置

如果 KataGo 启动方式有特殊参数，或者你想完全控制启动命令，可以使用 手工命令。 

/opt/homebrew/bin/katago gtp -model /path/to/model.bin.gz -config /path/to/gtp.cfg

填写后点击 添加手工配置。这个手工命令不会被 Auto Detect 自动填充， 也不会和普通 Engine Path / Model Path / Config 输入混用。

常见问题

Mac 上 Auto Detect 找不到 KataGo

先确认 Homebrew 安装成功：

katago version

如果命令不存在，重新安装：

brew install katago

然后回到 TensuGo，点击 Auto Detect。

引擎测试失败

  • Engine Path 指向 katago
  • Model Path 指向 .bin.gz 或 KataGo 支持的模型文件
  • Config 指向 GTP 配置文件

Mac Homebrew 安装时，优先使用 gtp_example.cfg 或可用的 GTP 配置。

删除配置后又出现

TensuGo 启动时不会自动扫描。只有你点击 Auto Detect 后， 系统里的候选引擎才可能重新出现在列表中。
