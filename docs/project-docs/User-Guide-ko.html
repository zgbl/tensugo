User Guide

TensuGo 사용자 가이드

TensuGo는 기보 복기와 로컬 KataGo 분석을 위한 바둑 앱입니다. Windows 64비트와 Mac Apple Silicon을 지원합니다.

Windows MSImacOS DMG

현재 버전: V0.7.50 (업데이트 2026-08-21).

V0.7.50 새로운 기능

복기 국면에서 문제 생성, 목표 레벨별 풀이와 랭킹. 엔진은 일반/인간형 듀얼 모드 설정과 메모리 모니터링 지원. 연구 문서는 바둑판 크롭, 미리보기 창, PDF·패키지 내보내기 지원. 일괄 분석 콘솔 추가.

TensuGo 설치

Windows 64비트

  1. Windows x64 설치 파일을 다운로드합니다.
  2. 설치 프로그램을 실행합니다.
  3. 처음 실행한 뒤 설정 > 엔진을 엽니다.
  4. KataGo 상태를 확인합니다.

Windows 버전에는 KataGo OpenCL 엔진이 포함되어 있습니다.

Mac Apple Silicon

  1. Mac Apple Silicon 버전을 다운로드합니다.
  2. TensuGo를 설치하고 실행합니다.
  3. Homebrew로 KataGo를 설치합니다.
  4. 설정 > 엔진에서 Auto Detect를 클릭합니다.
  5. 검색된 설정을 선택하고 Test Engine을 실행합니다.
brew install katago

Mac 버전에는 엔진과 모델이 포함되어 있지 않습니다.

KataGo 설정

설정 > 엔진에서 엔진 목록과 현재 설정을 확인할 수 있습니다.

Auto Detect
시스템의 KataGo, 모델과 설정 파일을 검색합니다.
Test Engine
현재 설정으로 엔진을 시작할 수 있는지 테스트합니다.
Choose Config
KataGo GTP 설정 파일을 직접 선택합니다.
저장 / 기본값
설정을 목록에 저장하고 기본 분석 엔진으로 지정합니다.
Reset to Default
현재 기본 설정을 지웁니다.

시작할 때 자동 검색하지 않습니다. 필요할 때 Auto Detect를 실행하세요.

Mac KataGo

Homebrew 설치를 권장합니다.

brew install katago
katago version

일반적인 경로는 /opt/homebrew/bin/katago와 /opt/homebrew/share/katago/입니다. 검색 후 Test Engine을 실행하세요.

Windows KataGo

설정 > 엔진에서 Auto Detect를 클릭하고 검색된 설정을 테스트한 뒤 기본값으로 지정합니다. 실패하면 Engine, Model, Config를 직접 선택하세요.

수동 명령

특수한 실행 인자가 필요하면 수동 명령을 사용합니다.

/opt/homebrew/bin/katago gtp -model /path/to/model.bin.gz -config /path/to/gtp.cfg

입력 후 수동 설정을 추가하세요. Auto Detect가 이 명령을 바꾸지는 않습니다.

자주 묻는 질문

Mac에서 KataGo를 찾지 못합니다

katago version을 실행하고, 명령이 없으면 brew install katago 후 Auto Detect를 다시 실행하세요.

엔진 테스트가 실패합니다

  • Engine Path가 KataGo를 가리키는지 확인합니다.
  • Model Path가 .bin.gz 파일인지 확인합니다.
  • Config가 GTP 설정 파일인지 확인합니다.

Mac에서 메모리가 해제되지 않습니다

macOS는 메모리 압축과 스와프로 메모리를 관리해, 앱이 해제한 메모리를 곧바로 '비어 있음'으로 처리하지 않고 압축/캐시 페이지에 남겨뒀다가 메모리 부하가 높아질 때 회수합니다. 이는 macOS의 고유 버그이지 TensuGo의 실수/미흡이 아닙니다——TensuGo는 메모리를 정상적으로 해제했지만 macOS가 점유를 즉시 시스템으로 돌려주지 않는 것입니다. TensuGo의 AI 분석은 한 번에 많은 메모리를 확보하므로 이 '바로 해제되지 않는' 현상이 두드러지고, 활동 모니터에서는 높은 사용량이 계속 보일 수 있습니다. 프로세스를 종료하면 메모리가 완전히 회수되어 사용량이 즉시 내려갑니다.

사용이 끝나면 TensuGo를 종료(Cmd+Q)하세요. 자리를 비울 때 분석을 오래 켜두지 마세요.
